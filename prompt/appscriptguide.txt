# 🚀 구글 앱스스크립트(GAS) 웹 앱 배포 가이드

이 가이드는 작성하신 코드를 인터넷 주소(URL)를 가진 실제 웹 앱으로 배포하는 방법과, 이후 코드를 수정했을 때 업데이트하는 방법을 안내합니다.

## 📝 처음 배포 전 필수 확인 사항
1. **코드 저장:** 앱스스크립트 편집기에서 `Ctrl + S` (또는 `Cmd + S`)를 눌러 작성한 코드를 모두 저장했는지 확인하세요. (저장되지 않은 코드는 주황색 점이 표시됩니다.)
2. **데이터베이스 초기화:** 구글 시트 새로고침 후 상단에 생긴 커스텀 메뉴를 눌러 시트 탭과 초기 데이터 세팅을 마쳤는지 확인하세요.

---

## 🟢 1단계: 처음 배포하기 (새 배포)
코드를 처음으로 인터넷에 띄우는 과정입니다.

1. 앱스스크립트 편집기 화면 우측 상단에 있는 파란색 **[배포(Deploy)]** 버튼을 클릭합니다.
2. 나타나는 메뉴에서 **[새 배포(New deployment)]** 를 선택합니다.
3. 팝업창 왼쪽 위에 있는 **톱니바퀴 아이콘(⚙️)** 을 누르고 **[웹 앱(Web app)]** 을 선택합니다.
4. 우측 설정 화면을 다음과 같이 맞춥니다:
   - **설명(Description):** 버전을 알아보기 쉽게 적습니다. (예: `v1.0 첫 배포`)
   - **다음 사용자로 실행(Execute as):** 반드시 **나(Me)** 로 설정합니다. (그래야 접속자들이 선생님의 구글 시트 DB에 접근하여 데이터를 읽고 쓸 수 있습니다.)
   - **액세스 권한이 있는 사용자(Who has access):** **모든 사용자(Anyone)** 로 설정합니다. (그래야 구글 로그인을 하지 않은 학생들도 앱에 접속할 수 있습니다.)
5. 설정이 끝났다면 하단의 파란색 **[배포]** 버튼을 누릅니다.

---

## 🔴 2단계: 구글 접근 권한 승인 (가장 중요)
처음 배포할 때 구글이 "이 앱이 당신의 구글 드라이브와 시트에 접근하려 한다"며 보안 경고를 띄웁니다. 본인이 만든 앱이므로 안심하고 승인하시면 됩니다.

1. **[액세스 승인(Authorize access)]** 버튼을 클릭합니다.
2. 본인의 구글 계정을 선택합니다.
3. ⚠️ "Google에서 확인하지 않은 앱"이라는 무서운 경고 창이 뜹니다. 당황하지 마시고 왼쪽 아래의 **[고급(Advanced)]** 글자를 클릭합니다.
4. 아래로 펼쳐진 내용 중 가장 밑에 있는 **[프로젝트 이름]으로 이동(안전하지 않음)** 링크를 클릭합니다.
5. 앱이 요구하는 권한(구글 시트 보기/수정 등)을 확인하고 **[허용(Allow)]** 버튼을 클릭합니다.

> 🎉 **축하합니다! 배포가 완료되었습니다.**
> 화면에 나타난 **'웹 앱 URL'** 아래의 주소를 [복사]하여 공유하면 누구나 선생님이 만든 웹 앱에 접속할 수 있습니다.

---

## 🟡 3단계: 코드 수정 후 업데이트하기 (재배포)
*(매우 주의! 코드를 수정하고 그냥 저장만 하면 배포된 사이트에는 적용되지 않습니다.)*
코드를 고친 뒤에 실제 웹 앱 화면에 반영하려면 반드시 버전을 올려서 **'업데이트'**를 해주어야 합니다.

1. 코드를 수정하고 저장(`Ctrl + S`)합니다.
2. 우측 상단의 **[배포(Deploy)]** 버튼을 누릅니다.
3. ⚠️ 이때 [새 배포]가 아니라, 반드시 **[배포 관리(Manage deployments)]** 를 클릭해야 합니다! *(새 배포를 누르면 주소가 자꾸 바뀝니다.)*
4. 나타난 팝업창의 왼쪽 목록에서 현재 사용 중인 배포를 클릭하고, 우측 상단의 **연필 모양 아이콘(수정 ✏️)** 을 클릭합니다.
5. 설정 화면에서 **버전(Version)** 항목의 드롭다운 상자를 열어 **새 버전(New version)** 을 선택합니다.
6. 버전에 대한 설명(예: `버그 수정 및 UI 변경`)을 간단히 적습니다.
7. 하단의 파란색 **[배포]** 버튼을 누릅니다.

> 💡 **Tip:** 이렇게 [배포 관리]를 통해 버전을 올리면 **처음 학생들에게 나누어 주었던 접속 URL이 바뀌지 않은 채로 코드만 최신으로 업데이트**됩니다.

---

### 🔍 (참고) 배포하지 않고 나만 빨리 테스트하고 싶을 때는?
코드를 한 줄 고치고 매번 버전을 올려 재배포하기 귀찮다면 **[테스트 배포(Test deployments)]** 기능을 활용하세요.
- **[배포] -> [테스트 배포 가져오기]** 를 누른 뒤 나오는 URL로 접속하세요.
- 이 주소(끝이 `/dev`로 끝남)는 선생님 계정으로 로그인된 브라우저에서만 열리며, 코드를 저장할 때마다 새로고침(F5)만 하면 수정 사항이 즉시 화면에 반영됩니다. 개발이 다 끝난 뒤에 정식으로 3단계(재배포)를 진행하시면 됩니다.
