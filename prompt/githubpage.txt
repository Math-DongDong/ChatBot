---
이 가이드는 내 컴퓨터에 있는 HTML 코드를 깃허브(GitHub)에 업로드할 새로운 공간(저장소)을 만들고, 이를 인터넷에서 누구나 볼 수 있는 무료 웹사이트(GitHub Pages)로 배포하는 전체 과정을 안내합니다.

---

## 🛠️ 1단계: 깃허브 저장소(Repository) 만들기
코드를 담아둘 클라우드 폴더(저장소)를 생성하는 과정입니다.

1. 깃허브 사이트(github.com)에 로그인합니다.
2. 화면 오른쪽 위 프로필 사진 옆의 **[+]** 기호를 누르고, **[New repository]**를 클릭합니다.
3. 생성 화면에서 다음 항목들을 설정합니다:
   * **Repository name (저장소 이름):** 원하는 프로젝트 이름을 영어로 적습니다. (예: `math-game`)
   * **Public / Private:** 깃허브 페이지를 무료로 사용하려면 반드시 **[Public(공개)]**을 선택해야 합니다.
   * **Add a README file:** 체크(선택)해 줍니다. (프로젝트 설명을 적을 수 있는 기본 파일이 함께 생성됩니다.)
4. 화면 맨 아래의 초록색 **[Create repository]** 버튼을 클릭합니다.

---

## 📁 2단계: 웹사이트 코드(파일) 업로드하기
내가 만든 HTML 파일들을 방금 만든 저장소에 올리는 과정입니다.

> ⚠️ **필수 확인:** 배포할 메인 화면의 파일 이름은 반드시 소문자 **`index.html`**이어야 합니다.

* **웹 브라우저에서 직접 올리기 (가장 쉬운 방법)**
  1. 생성된 저장소 화면에서 **[Add file]** 버튼을 누르고 **[Upload files]**를 선택합니다.
  2. 내 컴퓨터에 있는 `index.html` 파일과 관련된 폴더들을 화면 중앙으로 드래그 앤 드롭(끌어다 놓기) 합니다.
  3. 파일이 모두 올라가면 화면 하단의 **[Commit changes]** 버튼을 눌러 저장합니다.

---

## 🟢 3단계: 깃허브 페이지(GitHub Pages) 설정하기
업로드된 HTML 파일들을 '웹사이트' 형태로 변환해 달라고 깃허브에 지시하는 과정입니다.

1. 저장소 화면 상단 탭에서 가장 오른쪽에 있는 톱니바퀴 모양의 **[Settings(설정)]**를 클릭합니다.
2. 왼쪽 메뉴 목록을 아래로 조금 내려 **[Pages]**를 클릭합니다.
3. 화면 중앙의 **'Build and deployment'** 섹션을 확인합니다.
   * **Source:** `Deploy from a branch`로 둡니다.
   * **Branch:** 기본적으로 `None`으로 되어 있는 버튼을 눌러 **`main`** (또는 `master`) 브랜치를 선택합니다.
   * 그 옆의 폴더 경로는 **`/ (root)`**로 둔 상태에서 오른쪽의 **[Save]** 버튼을 클릭합니다.

---

## 🟡 4단계: 배포 진행 상황 확인하기 (Actions)
[Save] 버튼을 눌렀다면 깃허브 서버가 코드를 웹사이트로 조립할 때까지 잠시 기다려야 합니다.

1. 화면 상단 탭에서 **[Actions]** 탭을 클릭합니다.
2. 목록 맨 위에 **'pages build and deployment'**라는 작업이 보입니다.
   * 🟠 **노란색 아이콘:** 웹사이트를 만들고 있는 중입니다. (보통 1~2분 소요)
   * 🔴 **빨간색 엑스(X):** 에러가 발생하여 배포에 실패한 상태입니다.
   * 🟢 **초록색 체크(✔):** 배포가 완벽하게 성공한 상태입니다.

---

## 🔵 5단계: 완성된 내 웹사이트 접속하기
[Actions] 탭에서 초록색 체크가 떴다면, 드디어 웹사이트에 접속할 수 있습니다.

1. 다시 상단의 **[Settings] -> [Pages]** 메뉴로 들어갑니다.
2. 화면 맨 위에 **"Your site is live at `https://아이디.github.io/저장소이름/`"** 이라는 메시지와 함께 접속 주소가 나타납니다.
3. 해당 주소를 클릭하거나 [Visit site] 버튼을 눌러 내 웹사이트가 정상적으로 열리는지 확인합니다.

---

## 🔄 6단계: 코드 수정 및 업데이트 (재배포)

한 번 배포 설정을 마친 후에는 [Settings] 메뉴에 다시 들어갈 필요가 없습니다.

1. 내 컴퓨터(VS Code) 또는 깃허브 코드스페이스에서 코드를 수정하고 저장합니다.
2. 수정한 코드를 깃허브로 **커밋(Commit) 및 푸시(Push)**하여 업로드합니다.
3. 깃허브 서버에 코드가 올라오는 즉시 **자동으로 새로운 배포 작업이 시작**됩니다.
4. [Actions] 탭에서 초록색 체크가 뜰 때까지 기다린 후 사이트에 접속하면 최신 버전이 반영되어 있습니다.

---

## ⚠️ 자주 발생하는 문제 해결 (Troubleshooting)

* **Q. 코드를 수정해서 올렸는데, 인터넷 창에는 계속 옛날 화면이 나와요!**
  * **A (브라우저 캐시 문제):** 브라우저가 화면을 빨리 띄우기 위해 과거 화면을 기억하고 있어서 그렇습니다. 웹사이트 창을 띄운 상태에서 강력 새로고침인 **`Ctrl + F5`** (또는 `Ctrl + Shift + R`)를 누르시면 즉시 최신 화면으로 바뀝니다.
* **Q. 접속했더니 404 File not found 에러가 떠요!**
  * **A:** 99% 확률로 파일 이름이나 위치 문제입니다. 저장소의 가장 바깥쪽(최상위 경로)에 메인 파일이 있는지, 그리고 이름이 완벽한 소문자 **`index.html`**인지 반드시 다시 확인해 주세요. (`Index.html`은 에러가 납니다.)
