# 🚀 깃허브 페이지(GitHub Pages) 웹사이트 배포 가이드

이 가이드는 깃허브 저장소(Repository)에 올린 HTML/CSS/JS 코드를 무료 웹사이트로 발행하고 업데이트하는 방법을 안내합니다.

## 📝 배포 전 필수 확인 사항
* **메인 파일 이름:** 저장소의 가장 바깥쪽(최상위 폴더)에 있는 메인 HTML 파일의 이름이 반드시 **소문자 `index.html`**인지 확인하세요. (`Index.html` 등 대문자가 섞여 있으면 404 에러가 발생합니다.)

---

## 🟢 1단계: 깃허브 페이지 설정 및 배포하기

1. 배포하려는 깃허브 저장소(Repository) 페이지에 접속합니다.
2. 화면 상단 메뉴 탭 중에서 가장 오른쪽에 있는 톱니바퀴 모양의 **[Settings(설정)]**를 클릭합니다.
3. 설정 화면의 왼쪽 메뉴 목록에서 아래로 조금 내려가 **[Pages]**를 클릭합니다.
4. 화면 중앙의 **'Build and deployment'** 섹션을 확인합니다.
   * **Source:** `Deploy from a branch`로 설정되어 있는지 확인합니다.
   * **Branch:** 기본적으로 `None`으로 되어 있는 드롭다운 버튼을 눌러 **`main`** (또는 `master`) 브랜치를 선택합니다.
   * 그 옆의 폴더 경로는 **`/ (root)`**로 둔 상태에서 오른쪽의 **[Save]** 버튼을 클릭합니다.

---

## 🟡 2단계: 배포 진행 상황 확인하기 (Actions)

[Save] 버튼을 누른다고 즉시 웹사이트가 뜨지 않습니다. 깃허브 서버가 코드를 조립하는 시간이 필요합니다.

1. 저장소 화면 상단 메뉴 탭에서 **[Actions]** 탭을 클릭합니다.
2. 목록 맨 위에 방금 시작된 **'pages build and deployment'**라는 작업이 보일 것입니다.
   * 🟠 **노란색 빙글빙글 도는 아이콘:** 현재 깃허브 서버에서 웹사이트를 만들고 있는 중입니다. (접속자가 많으면 'Queued' 상태로 몇 분 대기할 수 있습니다.)
   * 🔴 **빨간색 엑스(X):** 코드나 설정에 문제가 생겨 배포에 실패한 상태입니다.
   * 🟢 **초록색 체크(✔):** 배포가 완벽하게 성공한 상태입니다.

---

## 🔵 3단계: 완성된 내 웹사이트 접속하기

배포가 성공(초록색 체크)으로 끝났다면 이제 접속할 수 있습니다.

1. 다시 상단의 **[Settings] -> [Pages]** 메뉴로 들어갑니다.
2. 화면 맨 위에 **"Your site is live at `https://아이디.github.io/저장소이름/`"** 이라는 메시지와 함께 주소가 나타납니다.
3. 해당 주소를 클릭하거나 [Visit site] 버튼을 눌러 웹사이트가 정상적으로 열리는지 확인합니다. 이 주소를 학생들에게 공유하시면 됩니다.

---

## 🔄 코드 수정 후 업데이트 (재배포) 방법

앱스스크립트와 달리 깃허브 페이지는 설정을 매번 다시 만질 필요가 없습니다.

1. 내 컴퓨터(VS Code 등)에서 코드를 수정하고 저장합니다.
2. 수정한 코드를 깃허브로 **커밋(Commit)하고 푸시(Push)**하여 업로드합니다.
3. 코드가 깃허브 서버에 올라오는 즉시, **자동으로 깃허브가 새로운 배포 작업을 시작**합니다.
4. [Actions] 탭에서 초록색 체크가 뜰 때까지 기다리기만 하면 됩니다.

---

## ⚠️ 자주 발생하는 문제 해결 (Troubleshooting)

* **Q. 코드를 수정하고 올렸는데, 인터넷 창에는 옛날 화면이 나와요!**
  * **A (브라우저 캐시 문제):** 웹 브라우저가 화면을 빨리 띄우기 위해 과거 화면을 기억하고 있어서 발생합니다. 해당 웹사이트 창을 띄운 상태에서 강력 새로고침인 **`Ctrl + F5`** (또는 `Ctrl + Shift + R`)를 누르시면 즉시 최신 화면으로 바뀝니다.
* **Q. 404 File not found 에러가 떠요!**
  * **A:** 99% 확률로 파일 이름이나 경로 문제입니다. 메인 파일이 폴더 안쪽이 아닌 **가장 바깥쪽 경로**에 있는지, 그리고 이름이 완벽한 소문자 **`index.html`**인지 다시 한번 확인해 주세요.
