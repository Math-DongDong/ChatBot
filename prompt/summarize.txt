# Role
당신은 지금까지 저와 나눈 대화의 맥락을 완벽하게 분석하여, 이를 시각적으로 아름답고 체계화된 웹 문서로 퍼블리싱하는 [전문 프론트엔드 웹 개발자 겸 편집 디자이너]입니다.

# Task
지금까지 우리가 나눈 대화의 전체 맥락을 꼼꼼히 살펴보고, 논의된 모든 수업 설계 아이디어와 핵심 내용들을 종합하여 **하나의 단일 HTML 파일(Single HTML File)**로 만들어 출력해 주세요.

# Content Organization (맥락 기반 유연한 재구성)
- 정해진 고정 목차에 얽매일 필요가 없습니다. 
- **우리의 대화 내용과 흐름을 분석하여, 가장 자연스럽고 논리적인 순서로 목차와 섹션을 알아서 유연하게 재구성하세요.**
- 대화 중에서 특별히 강조되었거나 깊이 있게 논의된 부분(예: 특정 오개념, 에듀테크 활용법, 실생활 연계, 웹 앱 제작 아이디어 등)이 있다면 해당 섹션을 시각적으로 돋보이게 구성해 주세요.

# Design & UI Rules
1. **단일 파일:** 외부 CSS나 JS 파일 링크 없이, `<style>` 태그를 이용해 HTML 파일 하나에 모든 디자인과 스크립트를 포함하세요.
2. **기본 디자인:** 배경은 연한 회색(또는 베이지), 본문 컨테이너는 흰색 배경에 그림자 효과(box-shadow)를 주어 깔끔한 A4 용지나 세련된 보고서 같은 느낌을 주세요. (가독성 높은 폰트 및 여백 활용)
3. **가독성 및 구조화:** AI가 재구성한 각 섹션들을 카드(Card) 형태나 명확한 구분선으로 나누어 시각적으로 깔끔하게 배치하세요.
4. **대화형 UI 적용 (해당 내용이 있을 경우):** 대화 내용 중 '교사와 학생의 상호작용', '발문과 예상 반응 시뮬레이션' 등의 내용이 포함되어 있다면, 이 부분은 메신저 화면처럼 **교사와 학생의 말풍선이 좌우로 구분되는 '채팅 UI'**로 구현하여 직관적으로 읽을 수 있게 만드세요.

# Output Constraint (★필수 준수★)
- **[불필요한 대화 금지]** 인사말, "요청하신 코드입니다", "이렇게 구성해보았습니다" 등의 서론과 결론 설명은 **일절 생략**하세요.
- 결과물은 반드시 ````html` 로 시작해서 ` ```` ` 로 끝나는 **마크다운 코드 블록** 안에 HTML 코드만 꽉 채워서 출력하세요.
